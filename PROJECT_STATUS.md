## Описание проекта

Тактическая игра "Морской Бой" в стиле WeGO (Write-Go) с детальной системой повреждений кораблей, базой данных кораблей и редактором отсеков.

---

## Реализованные функции

### 1. Боевая система

#### Фазы боя
- **Движение** - перемещение кораблей по гексагональной сетке
- **Планирование** - выбор целей для стрельбы
- **Выполнение** - расчёт попаданий с анимацией
- **Результаты** - статистика и переход к следующему ходу

#### Гексагональная сетка
- Размер: 42×42 гексов
- Каждый гекс = 5 метров
- Размер гекса: 15 пикселей (HEX_SIZE = 15)
- Отображение траекторий движения кораблей
- Визуализация дальности стрельбы
- Карта помещается целиком на экране 1920×1080 без скроллинга

#### Система стрельбы
- Расчёт вероятности попадания на основе точности корабля
- Пробитие брони с учётом типа снаряда и толщины брони
- Распределение урона по отсекам
- Отслеживание попаданий (hitMarkers) с указанием:
  - ID корабля и отсека
  - Номер хода
  - Нанесённый урон

### 2. Система повреждений

#### Типы отсеков
1. **Мостик** (bridge) - жёлтый цвет (#eab308)
2. **Система управления и обнаружения** (control_system) - жёлтый цвет (#eab308)
   - КДП, БИУС, Дальномер, Радар, Гидролокатор
3. **Вооружение** (weaponry) - тёмно-красный цвет (#7f1d1d)
   - ГК, вспомогательный калибр, торпедные аппараты, зенитки
4. **ГЭУ** (propulsion) - тёмно-синий цвет (#1e3a8a)
   - Котлы, турбины
5. **Руль** (rudder) - тёмно-синий цвет (#1e3a8a)
6. **Винты** (propellers) - тёмно-синий цвет (#1e3a8a)
7. **Боезапас** (ammunition) - тёмно-коричневый цвет (#78350f)
8. **Остальные отсеки** (other) - тёмно-зелёный цвет (#14532d)
   - Жилые и вспомогательные отсеки, включая топливо

### 3. Стратегическая карта Тихого океана

#### Основные возможности
- **Размер карты**: 9703 × 7767 пикселей
- **Viewport culling** - отрисовка только видимой области
- **Canvas-based рендеринг** для высокой скорости
- **Pan & Zoom** - перетаскивание мышью и масштабирование колесом
- **Тайловая система** - 42 части (6 рядов × 7 колонок)
- **Гексагональная сетка** - полупрозрачная сетка поверх карты (50% прозрачности, толщина линий 1px, загруженный образец гекса отображается без изменений)
- **Кэширование изображений** - загруженные тайлы кэшируются
- **IndexedDB** - хранение данных карты (поддержка до нескольких ГБ)

#### Работа с картами (Экспорт/Импорт)
- **📤 Экспорт** - сохранение карты в JSON файл для резервного копирования
  - Проверка наличия данных перед экспортом
  - Отображение размера файла и количества тайлов
  - Визуальная индикация состояния кнопки
  - Подсказки (tooltips) при наведении
  - **Модальное окно экспорта** с тремя способами сохранения:
    - Автоматическое скачивание файла
    - Копирование данных в буфер обмена
    - Ручное сохранение через текстовый редактор
  - Решение проблемы блокировки скачивания в iframe/предпросмотре
- **📥 Импорт** - загрузка карты из ранее сохранённого JSON файла
  - Проверка формата файла (.json)
  - Валидация структуры данных
  - Обратная связь о результатах импорта
  - Автоматическое сохранение в IndexedDB

### 4. База данных кораблей

#### Демо-корабли
1. **Ямато** (Япония, 1941) - линкор
2. **Бисмарк** (Германия, 1940) - линкор
3. **Айова** (США, 1943) - линкор
4. **Балтимор** (США, 1943) - крейсер
5. **Флетчер** (США, 1942) - эсминец
6. **Симкадзэ** (Япония, 1940) - эсминец
7. **Гневный** (СССР, 1938) - эсминец

### 5. Редактор отсеков

#### Карточка корабля (ShipDetailCard)
- Полноэкранный режим редактирования
- Сетка 56×13 клетки (каждая клетка = 5м)
- Загрузка фонового изображения корабля
- Перемещение изображения с сохранением позиции
- Кнопка "Закрепить изображение"
- Создание отсеков рисованием на сетке
- Множественное выделение (Shift+клик или рамка)
- Перетаскивание нескольких отсеков одновременно

## Технические детали

### Сборка проекта
```bash
npm install
npm run build
```

### Зависимости
- React 18.3.1
- TypeScript 5.7.2
- Vite 6.4.1
- Tailwind CSS 4.1.11

### Размер бандла
- JavaScript: ~250.74 kB (74.48 kB gzip)
- CSS: ~37.74 kB (6.53 kB gzip)
- Всего модулей: 45

### Хранение данных

#### IndexedDB
- **Назначение**: Хранение больших объёмов данных (до нескольких ГБ)
- **Что хранится**: 
  - Стратегическая карта (тайлы PNG, ~35 МБ)
  - База данных кораблей
  - Настройки пользователя
- **Преимущества**:
  - Работает офлайн после первой загрузки
  - Быстрая повторная загрузка
  - Не требует сервера
- **Ограничения**:
  - Данные привязаны к домену
  - Удаляются при очистке кэша браузера
  - Не синхронизируются между устройствами

#### Резервное копирование
- **Экспорт в JSON**: Сохранение карты на компьютер для переноса между устройствами
- **Импорт из JSON**: Восстановление карты из файла
- **Рекомендация**: Регулярно экспортировать карту для защиты от потери данных
